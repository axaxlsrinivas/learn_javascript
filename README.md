# Learn JavaScript

This repository contains JavaScript code examples and notes for learning core JavaScript concepts. Each file demonstrates a specific topic with code and comments.

## Files Overview

- `arrowfunctions.js`: Examples of arrow functions, concise syntax, and higher-order functions using arrow functions.
- `collections.js`: Examples and notes on JavaScript collections (arrays, sets, maps, etc.).
- `iterateloops.js`: Demonstrates different iteration and loop constructs in JavaScript.
- `jsobjects.js`: Working with JavaScript objects, properties, and methods.
- `keywords.js`: Overview and examples of important JavaScript keywords.
- `operators.js`: Usage of various JavaScript operators.
- `parsefunctions.js`: Parsing functions and related examples.
- `profilelookup.js`: Example of a profile lookup function.
- `randomfractions.js`: Generating random fractions and numbers in JavaScript.

## How to Use

Open any `.js` file to see code examples and run them in your browser console or Node.js environment.
